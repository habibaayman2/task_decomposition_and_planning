# Excavator Maintenance & Safety Policy (IronBridge Policy #3)

## Daily Pre-Operation Checks
- Inspect hydraulic fluid levels
- Check track tension and undercarriage
- Verify bucket teeth condition
- Test all control levers and emergency stop

## Common Failure Symptoms
- **Engine won't start**: Check battery, fuel filter, glow plugs
- **Hydraulic arm slow**: Low hydraulic fluid or clogged filter
- **Overheating**: Clean radiator, check coolant level
- **Track slipping**: Adjust track tension, inspect drive sprocket

## Repair vs Replace Guidelines
- If repair cost &lt; 40% of equipment value → **Repair**
- If downtime &gt; 5 days → Consider **Replacement**
- Always check remaining project budget before major repairs

## Safety Requirements
- Lock-out/tag-out before any maintenance
- Only certified technicians perform engine repairs
- Document all repairs in equipment log
